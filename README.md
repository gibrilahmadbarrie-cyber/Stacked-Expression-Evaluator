# Stack-Based Mathematical Expression Evaluator
## Project Overview
This project evaluates mathematical expressions using a stack in Python
## Project files
- main.py: Python source code.
- input.txt: input expressions.
- output.txt: calculated results.
## How to Run
1. open main.py in PyCharm
2. Right-click inside the editor.
3. Select Run 'main'
4. Open output.txt to see the results.
## Testing
The program was tested using three mathematical expressions, producing the results 13, 16, and -10.
